# Renovivo — Блог план (12 приоритетни статии)

Стратегическа цел: заемане на позиции по high-intent локални запитвания за
ремонти в София + информационни търсения, които водят читателя до конкретна
услуга (bathroom, full-renovation, microcement, kitchen).

Всяка статия следва схема:
- Основна ключова дума (primary keyword)
- Slug + title (≤60 знака) + meta description (140–160 знака)
- H1 + препоръчани H2/H3
- Целева дължина
- Вътрешно линкване (към услуги / към други статии)
- Schema (Article + FAQPage, а където е приложимо HowTo)

## Правила за всяка статия

- **Език:** български, естествен, без клишета и без "AI-звучене".
- **Автор:** "Екипът на Renovivo" (Person / Organization schema).
- **Featured image:** реален снимков материал от портфолиото, alt text с ключова дума.
- **CTA:** в началото (връзка към /contact) и в края ("Заявете безплатен оглед").
- **Вътрешно линкване:** минимум 3 линка към релевантни услуги + 1 към друга статия.
- **Schema:** Article + BreadcrumbList; FAQPage когато има ≥3 Q&A.
- **Мета-данни:** уникален title (≤60 знака) и description (140–160 знака).
- **Обновяване:** ревю на всеки 6 месеца, `dateModified` в JSON-LD.
