## Visual tokens
- Light warm off-white canvas, sandy / natural material textures, olive / muted-green buttons, graphite content.
- Typography: Onest interface + Literata editorial/italic accented headlines (Cyrillic).
- Clean uppercase RENOVIVO logo with an architectural monogram.
- Soft, understated depth (blurred gradient overlays, elegant image crops, gentle hover and transitions), never garish animations.
- Large interior photographs and high image-to-text ratio.
- **Mobile-first priority:** immediate visible interior in hero (not an image below the fold), phone/menu icons in header, tappable CTA, horizontal swipe galleries, fixed bottom contact/booking bar.
- Desktop: immersive split-gradient interior hero, trust icons, photographic service carousel, project carousel, process+estimator, craft/photo/video, final consultation CTA.
- User preference: less "table"/empty white sections, more editorial spatial storytelling, visual hierarchy, image density, multimedia, and useful interactivity.
- Preserve existing active calculator, inspection request form, bilingual support, SEO/SSR, cookie consent.
- Avoid invented verified projects, testimonials or company metrics. Existing image assets need source verification before marketing them as actual completed work.
- Respect reduced motion and responsive image loading.

**Implementation:** source components and CSS in main; the uploaded reference PNGs are visual references, not to be rendered as flat webpage screenshots.
